# Tugas 4

Program web sederhana untuk mendemonstrasikan manipulasi **DOM (Document Object Model)** secara interaktif dan bertahap[cite: 1].

## Fitur
1. **Input Dinamis (`ok1`)**: Membuat kolom teks pilihan sesuai jumlah angka yang dimasukkan (1–10)[cite: 1].
2. **Pilihan Interaktif (`ok2`)**: Mengubah teks pilihan menjadi elemen *Radio Button* secara otomatis[cite: 1].
3. **Validasi Email (`ok3` & `ok4`)**: Memastikan format email valid menggunakan *regex* sebelum menampilkan ringkasan data[cite: 1].

## Fungsi Utama DOM
- `document.createElement()`: Membuat elemen HTML baru secara dinamis[cite: 1].
- `appendChild()`: Menambahkan elemen baru ke dalam halaman[cite: 1].
- `innerHTML`: Mengosongkan atau memperbarui isi kontainer HTML[cite: 1].
